
# Assistants OpenAI

## Логика к помощнику

https://confluence.ancor.ru/pages/viewpage.action?pageId=3152708765

## Описание

`Assistants` — это набор классов для взаимодействия с API OpenAI, предназначенных для управления тредами и помощниками. Эти классы позволяют создавать треды, добавлять сообщения к уже существующим тредам, запускать помощников для обработки сообщений и получать результаты их работы.

## Описание классов

### ThreadManager

Класс для управления тредами.

**Методы:**

- **`__init__(self, client, vacancy_info)`**  
  Инициализирует менеджер тредов.  
  **Параметры:**  
  - `client` — клиент OpenAI.  
  - `vacancy_info` — словарь с информацией о вакансии.
    - `title` - название должности,
    - `company_name`- название компании,
    - `responsibilities` - обяззаности на вакансии,
    - `work_format` - формат работы,
    - `firm_description` - описание компании,
    - `vacancy_url` - ссылка на вакансию,
    - `questions` - вопросы для скриннинга.

- **`create_thread(self)`**  
  Создает новый поток сообщений с информацией о вакансии.  

  **Возвращает:** созданный тред.

- **`add_message_to_thread(self, thread_id, message)`**  
  Добавляет сообщение в существующий поток.  
  **Параметры:**  
  - `thread_id` — ID треда.  
  - `message` — сообщение для добавления.
  
  **Возвращает:** добавленное сообщение.

### RunManager

Класс для управления запусками помощника OpenAI.

**Методы:**

- **`__init__(self, client, assistant_id)`**  
  Инициализирует менеджер запусков.  
  **Параметры:**  
  - `client` — клиент OpenAI.  
  - `assistant_id` — ID помощника.

- **`create_run(self, thread_id)`**  
  Создает новый запуск для данного потока сообщений.  
  **Параметры:**  
  - `thread_id` — ID треда.  
  
  **Возвращает:** созданный запуск.

- **`wait_for_result(self, thread_id, run_id)`**  
  Ожидает завершения выполнения запуска и возвращает результат или метку "human_needed", если ответ содержит фразу "Извините, не могу сразу ответить, мне нужно подумать".  
  **Параметры:**  
  - `thread_id` — ID потока.  
  - `run_id` — ID запуска.  
  
  **Возвращает:** результат ответа или метку "human_needed".

### Assistants

Основной класс для работы с помощниками OpenAI.

**Методы:**

- **`__init__(self, assistant_id, api_key, vacancy_info)`**  
  Инициализирует класс с ID помощника, API-ключом и информацией о вакансии.  
  **Параметры:**  
  - `assistant_id` — ID помощника.  
  - `api_key` — API-ключ OpenAI.  
  - `vacancy_info` — словарь с информацией о вакансии (имя компании, название вакансии, обязанности, URL вакансии).

- **`create_thread(self)`**  
  Создает новый тред для текущей вакансии.  

  **Возвращает:** созданный тред.

- **`add_message_and_run(self, thread_id, message)`**  
  Добавляет сообщение в существующий тред и создает новый запуск.  
  **Параметры:**  
  - `thread_id` — ID существующего треда.  
  - `message` — сообщение для добавления в тред.  
  
  **Возвращает:** созданный запуск.

- **`get_result(self, thread_id, run_id)`**  
  Ожидает завершения выполнения запуска и возвращает результат или метку "human_needed", если ответ содержит фразу "Не могу сразу ответить, мне нужно подумать".  
  **Параметры:**  
  - `thread_id` — ID треда.  
  - `run_id` — ID запуска.  
  
  **Возвращает:** результат ответа или метку "human_needed".
