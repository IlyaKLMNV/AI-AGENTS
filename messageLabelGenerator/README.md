# messageLabelGenerator


В отличие от прошлой реализации данный классификатор работает на сонове ЛЛМ. 

Промпт по классификации: pmpt_68e8b47991f0819094f05d51eb5780a10ff88c389be96726

На вход получает сообщение кандидата, как есть без каких либо предобработок.

На выходе - строка, значение одного из классов:
- reason_farewell - отказ с причиной (логика остается такая же)
- no_reason - отказ без причины (логика остается такая же)
- human_needed - позвать человека (логика остается такая же, у нас эти диалоги обрабатывает дальше ассистент скрининга)
- acceptance - НОВОЕ, сообщение, где явно выражен интерес без каких либо вопросов. Для этого класса мы кандидатов должны автоматически кидать на этап Неймчек. Диалог с ними дальше продолжается как для класса human_needed
